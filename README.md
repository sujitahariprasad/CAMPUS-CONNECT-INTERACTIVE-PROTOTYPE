> Campus Connect – Interactive Prototype(Thiranex Internship)

> Project Overview
Campus Connect is a UI/UX prototype designed to help college students explore campus events, view event details, and register for events through a simple interface.

> Screens Included
- Home Page
- Events Listing
- Event Details
- Registration Form
- Registration Confirmation
- My Events
